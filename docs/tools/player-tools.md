# Player tools

| Tool | Purpose |
| --- | --- |
| Tactical briefing | Review the selected map, victory condition, and team objective before deployment. |
| Loadout and deployment | Choose division compositions, formations, vehicle presets, and available spawn points. |
| Infantry command HUD and minimap | Issue orders and track divisions, anchors, and objectives. |
| Vehicle instruments | View ammunition, condition, and mode-specific controls while driving, flying, or operating a ship. |
| Showroom and customization area | Inspect vehicles and preview appearance, effects, and sounds. |
| Profile and mastery | Track combat statistics, progression, and unlocks. |
| Input and visual settings | Use touch or PC controls and adjust visual quality. |
